Ethereum staking: attributed validator set

Who stands behind every active validator (organisation, allocator, operator, and where known principal and custodian), the execution-layer addresses identified, and the decisions, sources and methods behind each attribution, with every validator's place in the treemap since genesis. Data through epoch 485,775 (2026-10-30T12:00:23Z), generated 2026-10-31T04:45:18Z. README has the columns and a query that rebuilds the treemap from these files.

All files, from a shell:

for f in validators.csv.gz addresses.csv entities.csv boxes.csv decisions.json sources.json methods.json attributions.parquet stake.parquet nodes.parquet treemap.parquet README.md manifest.json; do curl -fO "https://pintail.xyz/staking/treemap/data/dataset/$f"; done

The sha256 of each file is in manifest.json. The decisions behind the attributions each have a page with their evidence, sources and what would change them, and every organisation has a page with the roles it has played since the beacon chain's genesis.
