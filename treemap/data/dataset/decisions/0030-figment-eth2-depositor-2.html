Explanation

The contract 0xb4e2…c76b is a Figment depositor contract: validators first deposited through it are attributed to Figment as allocator and operator, while each client keeps its own withdrawal address. 78 validators were deposited through it between October 2021 and February 2022, from eight sending accounts; all have since exited.

Identification. Figment's documentation names two batch deposit contracts as its own. One of them was created by the account that also created this contract and Figment's other depositor contract (decision 0029); all have the same verified source code (FigmentEth2Depositor). A contract created by the account that created Figment's documented contract, with Figment's own code, is taken to be Figment's.

Why Figment is the allocator. A client depositing through a provider's contract has chosen that provider, who generates the keys and runs the validators; the client keeps the withdrawal address (decision 0005).

Limits. The contract's deposit function is open to anyone while it is not paused, so a deposit through it does not by itself prove that Figment ran the validator. Explorer labels are recorded as leads. The decision would change with a Figment statement contradicting it, or evidence that some depositors used the contract with keys Figment did not run.

What would change it

A Figment statement contradicting it, or evidence some depositors use it with keys Figment does not run.
