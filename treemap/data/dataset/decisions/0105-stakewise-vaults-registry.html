Explanation

The contract 0x3a00…c20e is StakeWise V3's vault registry: every StakeWise V3 vault is added to it when created, and validators withdrawing to a registered vault are attributed to StakeWise V3 as allocator. By October 2026 the registry listed 254 vaults; about 3,000 of their validators were active, with some 0.29M ETH, many of them compounding.

Identification. StakeWise's own deployment list names this contract as its V3 VaultsRegistry. It was created in October 2023 and has recorded each vault's creation since. The shared MEV escrow named in the same list is the fee recipient of many StakeWise validators, which helped identify them.

Why StakeWise is shown as the allocator. Each vault's administrator chooses that vault's operators, so the choice is made within the protocol, by many parties; as with Rocket Pool, the protocol is shown as the allocator. Distinguishing vaults, for example the Genesis Vault run by StakeWise's DAO from institutions' private vaults, would be a possible refinement.

The decision would change if StakeWise's deployment list named a different registry, or if vaults were found to be registered elsewhere.

What would change it

StakeWise's deployment list naming a different registry, or vaults registered elsewhere.
