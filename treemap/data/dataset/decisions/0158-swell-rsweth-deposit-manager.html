Explanation

The contract 0x5e63…4889 is the Deposit Manager of Swell's restaking token rswETH. Validators whose first deposit it sent, and validators withdrawing to the EigenLayer pod those deposits name, are attributed to Swell rswETH as allocator. Between January and May 2024 it deposited 4,018 validators, holding as much as 129k ETH; none is active now. Swell's later restaking deposits, made through its EigenLayer manager, are attributed in decision 0159.

Identification on chain. The rswETH token contract names an access-control manager; that manager names this contract as its DepositManager, and the Deposit Manager names the same access-control manager and an EigenLayer manager that in turn points back to it. The 4,018 validators all withdraw to an EigenLayer pod owned by the Deposit Manager; Swell's published code now refers to that pod as deprecated, its restaking having moved to the EigenLayer manager's staker proxies.

Consistency with public information. DefiLlama has measured Swell's restaking value from the rswETH contract since 30 January 2024, the day after the first deposit. This is the same self-identification on chain by which Swell's swETH is recorded (decision 0157). The decision would change with a Swell statement contradicting it, or evidence that the rswETH contracts are not Swell's.
