Explanation

Validators withdrawing to 0xe839…506c or 0xd5f8…7634 are attributed to OKX's staking as allocator. In October 2026 about 5,960 active validators withdraw there, some 618,000 ETH (0xe839…506c: 5,572 validators, 178,000 ETH; 0xd5f8…7634: 388 compounding validators, 440,000 ETH).

OKX publishes a wallet file with each proof of reserves. The file for 3 October 2026 lists, under "Native ETH Staking", 7,290 validators withdrawing to 0xe839…506c and 388 withdrawing to 0xd5f8…7634, each row with the message "I am an OKX address" signed by the withdrawal address. The signer of every row recovers to the address the row names, so whoever compiled the file holds those keys. Every validator active at the two addresses in October 2026 is in the file.

Decision 0025 already identified OKX's deposit account from the same file. This decision attributes the two withdrawal addresses directly, so the validators rest on OKX's own listing rather than on the deposit route. Who operates them is not stated in the file, so no operator is recorded.

What would change it

A later OKX reserve file leaving these addresses out, or an OKX statement that their validators belong to clients.

Evidence

Transactions and contract calls anyone can repeat on their own node.
