Explanation

The contract 0x9b8c…e394 is Kiln's first batch deposit contract, now retired: validators first deposited through it are attributed to Kiln as allocator and operator, while each client keeps its own withdrawal address. 21,323 validators were deposited through it between November 2021 and March 2024, from 123 sending accounts; they held as much as 535k ETH, and almost all have since exited.

Identification. Kiln's documentation names this contract as its V1 batch deposit contract and marks it deprecated, and Kiln's code repository names the same contract. Its successor is decision 0034.

Why Kiln is the allocator. A client depositing through a provider's contract has chosen that provider, who generates the keys and runs the validators; the client keeps the withdrawal address. This is the rule applied to all providers' depositor contracts (decision 0005), including where the client is an integrator or a custodian.

Limits. The contract lets anyone deposit, so a few depositors may have used it with keys run by other operators. The decision would change with a Kiln statement contradicting it, or evidence that some depositors used the contract with keys Kiln did not run.

What would change it

A Kiln statement contradicting it, or evidence some depositors use it with keys Kiln does not run.

Evidence

Transactions and contract calls anyone can repeat on their own node.
