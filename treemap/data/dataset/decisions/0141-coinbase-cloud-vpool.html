Explanation

Validators withdrawing to 0x116b…5e9f, the withdrawal contract of a vPool that names itself and its operator Coinbase Cloud, are attributed to Coinbase Cloud as allocator. The vPool, a pooled-staking contract built from Kiln's code, deposited 5,064 validators; about 3,550 were active in October 2026 with some 0.11M ETH. The decision replaces an earlier one (0040) that had given the pool to Kiln.

What the pool records about itself. The pool's name() returns "Coinbase Cloud vPool Shares", and when its factory was created it recorded "Coinbase Cloud" as its operator's name; the record has never changed. Kiln's own vPool, built from the same code and the same factory system, names itself "Kiln vPool Shares" and records "Kiln" (decision 0039). Both factories were created through the same deployment contract, so Kiln's tooling set up both.

Keys and graffiti. Every key added to the Coinbase Cloud factory came from its administrator account, which was first funded by an account that had received ETH from one of Coinbase's custody wallets. No transfer links the Coinbase Cloud factory's accounts to Kiln's. Of the 14,065 blocks its validators have proposed, 13,846 are blank and the rest carry client version strings; none names Kiln, whereas every block of Kiln's own vPool is signed "Kiln.fi". Every deposit crediting the withdrawal contract came from this pool.

Why Coinbase Cloud is the allocator. The names a contract records for itself are set by whoever sets the pool up for its owner, so they say whose product it is. Whether Coinbase Cloud runs the validators itself or Kiln runs them as a white-label provider, the pool is Coinbase Cloud's offering, which makes Coinbase Cloud the allocator. No operator is recorded. The single funding link to Coinbase's custody wallet fits this but would not on its own identify the pool.

The decision would change with a Coinbase or Kiln statement that this pool's validators are allocated by Kiln or another party.

What would change it

A Coinbase or Kiln statement that the pool's validators are allocated by Kiln or by another party.
