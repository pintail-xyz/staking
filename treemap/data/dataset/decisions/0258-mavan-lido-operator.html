Lido operator 4/26 is MAVAN's.

Operator or ownerOperated by MAVAN from 2026-07-28, for MAVAN - PTO · decided 2026-10-28

Lido's node operator 4/26 (MAVAN - PTO) is run by MAVAN.

Grounds

  • On chainOperator 4/26 named itself "MAVAN" on 28 July 2026, then "MAVAN - PTO"
  • First partyMAVAN is BitMine's staking subsidiary, which owns Pier Two

Explanation

In Lido's second curated module, operator 26 set its name to "MAVAN" on 28 July 2026 and to "MAVAN - PTO" on 4 August 2026. MAVAN Holdings is BitMine's staking subsidiary, which owns Pier Two (decisions 0261 and 0262). The operator is recorded as run by MAVAN from its first name.

What would change it

A Lido or MAVAN statement that the operator belongs to another company.

Evidence

Transactions and contract calls anyone can repeat on their own node.
