Explanation

The account 0x5a00…3a11 makes the beacon deposits for OKX's ETH staking, and validators withdrawing to the addresses it deposits to are attributed to OKX's staking as allocator. 38,902 validators were first deposited by it between December 2020 and September 2026; about 6,500 were active in October 2026 with some 0.64M ETH, increasingly in compounding validators.

OKX's own proof of reserves. OKX publishes a wallet file with each proof of reserves; the snapshot of 3 October 2026 was used. The file lists this account itself among OKX's addresses. It also lists 7,718 validators as native ETH staking, 7,678 of them withdrawing to this account's two withdrawal addresses, 0xe839…506c and 0xd5f8…7634. Each staking row carries the signature of a message reading "I am an OKX address". Recovering the signer of every one of the 8,031 staking rows gives in each case the withdrawal address the row names, so OKX holds those addresses' keys.

The list was checked in both directions. Every validator withdrawing to either address and active at the snapshot is on the list, and every listed validator that appears in the sampled beacon state is one of them. No other account has ever deposited to either address. Withdrawn ETH goes to addresses OKX's file also lists.

What this establishes. A row in the file shows that OKX holds the validator's withdrawal key and counts the validator in its reserves as staked customer ETH, which makes OKX the allocator. The file does not say who operates the validators, so no operator is recorded. The decision would change with an OKX statement contradicting it, or evidence that the account deposits on clients' instructions to keys they chose.

What would change it

An OKX statement contradicting it, or evidence it deposits keys chosen by clients.
